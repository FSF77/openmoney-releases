### 💻 Como Instalar Manualmente
1. Baixe o [OpenMoney.zip](https://github.com/FSF77/openmoney-releases/raw/main/downloads/OpenMoney.zip).
2. Dê dois cliques para descompactar o `OpenMoney.app`.
3. Arraste para a sua pasta **Aplicativos** (`/Applications`).
4. Pronto! O app se atualizará automaticamente a partir das próximas versões através do menu **OpenMoney > Buscar Atualizações...**.
